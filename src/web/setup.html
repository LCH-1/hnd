1 / 7코드 확인

시작 코드를 확인합니다

기존 작업 공간이 여러 개인 서버에서만 선택 코드가 필요합니다.

연결할 작업 공간의 선택 코드 만들기 docker exec hnd-server node /app/bin/hnd-server.mjs account bootstrap --tenant TENANT_ID TENANT_ID를 연결할 기존 작업 공간 ID로 바꾼 뒤, 표시된 코드를 아래에 입력하세요.

코드는 URL이나 브라우저 저장소에 남기지 않으며 계정을 만들 때 한 번만 사용합니다.

2 / 7계정

계정 이름을 정하세요

이메일과 비밀번호는 필요하지 않습니다. 로그인은 다음 단계에서 만드는 패스키로 보호합니다.

영문, 숫자, 점, 밑줄, 빼기 기호를 사용할 수 있습니다.

앱 화면과 기기 기록에 표시됩니다.

소유자 계정이 계정이 사용자 초대와 서버 가입 정책을 관리합니다. 생성이 끝나면 공개 초기 가입은 자동으로 닫힙니다.
3 / 7패스키

패스키로 계정을 보호하세요

기기의 화면 잠금, 지문·얼굴 인식, PIN 또는 보안 키를 사용합니다. 생체정보는 HND 서버로 전송되지 않습니다.

  • 현재 서버 주소에만 묶여 피싱을 막습니다.
  • 서버에는 로그인 공개키만 저장합니다.
  • 나중에 보안 화면에서 두 번째 패스키를 추가할 수 있습니다.

웹 계정패스키로 본인 확인

            6 / 7PC 연결
            
          

          
이 계정에 PC를 연결하세요

          

            웹에서 일회용 코드를 만들고 연결할 PC에서 한 번 사용합니다.
          


          

            웹에서만 쓴다면 설치하지 않아도 됩니다.
            

              연결 도구는 이 PC의 Git과 Claude Code·Codex·Cursor를 이어 룰을
              자동으로 불러오고, 진행 상태를 저장하고, 오프라인 변경을 다시
              동기화할 때 필요합니다.
            

          


          

            

              1
              

                
실행할 PC 선택

                

                  운영체제
                  

                    
                    
                    
                  

                

                

                  설치 상태
                  

                    
                    
                  

                

                

                  명령을 실행할 PC의 운영체제와 설치 상태를 선택하세요.
                

                

                  브라우저가 아니라 실제 터미널을 연 PC를 기준으로 선택합니다.
                

              

            

            

              2
              

                
PC 연결 명령 만들기

                

                  PC 이름을 정한 뒤 패스키로 확인하면, 15분 동안 유효한 실행 명령을 만듭니다.
                

                

                  
                  
                  
                

                

                  패스키 창을 닫아도 다시 누르면 됩니다. 응답이 멈출 때만 인증을 취소하세요.
                

                

                  
                

              

            

            

              3
              

                
새 PC 터미널에서 실행

                

                  위에서 연결 명령을 만든 뒤 블록 전체를 한 번 복사해 실행하세요. 프로젝트는 이후 Git 저장소에서 AI 세션을 열 때 자동으로 등록됩니다.
                

                한 번에 실행
                

                  어느 폴더에서 실행해도 됩니다. 위 선택에 맞는 짧은 명령만 표시합니다.
                

                

                  

                  
                

                

                  연결 코드가 포함되므로 명령을 공유하지 마세요. 이후 Git 저장소에서 Claude Code·Codex·Cursor를 시작하면 프로젝트와 기본 환경을 자동 등록합니다.
                

              

            

          

          

            
            

              PC 연결을 기다리는 중명령이 완료되면 자동으로 확인합니다.
            

          

          

            로그인한 계정이 모든 PC의 연결 기준입니다서버가 계정의 암호화 키를 보호해 관리하므로 첫 PC나 기존 PC의
              승인이 필요하지 않습니다. 서버가 잠시 꺼지면 각 PC는 마지막 로컬
              사본으로 계속 작업하고 연결이 복구되면 자동 동기화합니다.
